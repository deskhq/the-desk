# Cold-load critical path: where the bytes are

Findings for wayfinder ticket [#1243](https://github.com/deskhq/the-desk/issues/1243), on the
[navigation feels instant](https://github.com/deskhq/the-desk/issues/1232) map.
Throwaway branch, never merged. `attribute.py` is the harness every child of the
navigation epic should measure with, so the numbers stay comparable.

## Method

`vite build --sourcemap`, then walk each chunk's sourcemap mappings to attribute
every generated byte to the source module it compiled from. Raw bytes are exact.
Gzip exists only per file (compression is global to a chunk), so a per-module
gzip figure is the module's raw share at the chunk's own ratio, and is labelled
`est` everywhere. The entry chunk's ratio is 3.29, `Show`'s is 4.0.

Measured against `develop` at dff953de. Local `gzip -6` runs ~6% above the wire
bytes the [baseline](https://github.com/deskhq/the-desk/issues/1233) recorded on
`demo.thedeskhq.app`, which serves brotli. Compare deltas, not absolutes.

### The duplicate Vue

`vuedraggable`'s `module` field points at `dist/vuedraggable.umd.js`, a UMD build
that `require`s Vue. Rollup therefore pulls `vue/dist/vue.cjs.prod.js` **plus
`@vue/compiler-core` and `@vue/compiler-dom`** into the entry chunk: 78K raw of
template compiler the app never calls, alongside a second copy of the Vue runtime
that already ships as its own 47K chunk. The package also ships uncompiled source
at `src/vuedraggable.js`, so aliasing to it compiles against the app's own Vue.

Two thirds of the sidebar's drag cost is this accident.

## What is already split (and so is not a lever)

Every route-level split the ticket imagined already exists: `Analytics` is its own
68K chunk (all of unovis and d3), the emoji picker its own 41K, the zxcvbn language
packs their own 600K+220K, and Inertia pages resolve lazily. The chunk named
`wayfinder-*.js` is **not** route helpers, it is `@inertiajs/core` (75.6K raw),
`@inertiajs/vue3`, `es-toolkit` and `laravel-precognition`.

There is no route-level split left to make. Everything remaining is inside the
entry chunk and inside `Show`.

To paint a channel you need the masthead, the virtualized list, the row and the

## The plan this produced

~103K gz est. against the ~105K needed, in four children:

1. Alias `vuedraggable` to its source build, `vite.config.ts` only (~24K).
2. A shared idle warm-up helper plus an async drag wrapper in the three sidebar
   components (~28K).
3. Async `DialogHost` and async dock panels, which take the date and passkey
   tails with them (~32K).
4. Async channel interaction surfaces behind the existing `ChannelDialogs` seam
   (~19K).

Reserve, out of scope unless the epic's measured total lands over 550K: deferring
the realtime connect (~22K), the only lever that trades behaviour for bytes.

Follow-up, not a child: the wayfinder-generated `actions/`/`routes/` modules
attach helpers as property assignments, which rollup cannot tree-shake (~19K).
